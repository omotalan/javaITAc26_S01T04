# Control d'Excepcions
**Descripció**: Sprint 1, Tasca 4, Nivell 1, Exercici 3

## 📌 Exercici 3: Control d'Excepcions
```
En aquest exercici treballarem el llançament i la detecció d'excepcions en Java. L’objectiu és entendre com gestionar errors esperats mitjançant el testing automatitzat.
Enunciat

Crea una classe Java que contingui un mètode públic el qual provoqui una excepció del tipus ArrayIndexOutOfBoundsException. Aquest mètode pot, per exemple, intentar accedir a una posició inexistent d’un array.

A continuació, implementa una classe de test amb JUnit 5 que verifiqui que el mètode llança l’excepció esperada quan es donen les condicions corresponents.
```

## ✨ Funcionalitats (si és aplicable)
Aquí he creat només la classe de mètode, i faig el test amb assertThrows
